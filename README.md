# Forward Deployed Engineer Field Guide

A concise VitePress research site about what forward deployed engineers do, what internship and full-time postings ask for, and how the role varies by domain.

**Read the site:** https://asu245.github.io/forward-deployed-engineer-field-guide/

## Local development

```sh
npm ci
npm run docs:dev
```

## Deploy

GitHub Actions builds `docs/` with VitePress and publishes it to GitHub Pages on pushes to `main`.

Research snapshot: 12 November 2026. See [method and limits](docs/method.md).
